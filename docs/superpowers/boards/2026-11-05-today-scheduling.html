The rule (my proposal, numbers to tune): the next gap is worked out from the days that actually passed since you last did it, and from how it felt. It is never worked out from the date it was planned for.

  • Still hard → tomorrow.
  • Getting there → a bit longer than the time that passed (× 1.2), at least 3 days. Done early: half the gap it had.
  • I've got it → time that passed × 2.5, at least a week. Done early: the gap it already had, so it never shrinks for remembering and never balloons.
  • Easy → time that passed × 4, at least 3 weeks; done early, the gap it had × 1.3.

Nothing new is saved: the dates and feelings of the sets you logged are enough, so it stays within the app's "urgency is never stored" rule.
