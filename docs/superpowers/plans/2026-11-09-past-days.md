# Past days: the new look — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo a slot builds natively (CLAUDE.md "Building in a slot").

**Goal:** A past day on Today looks like Done for today (tiles, one list, faces), its band has a day strip (‹ relative day ›, Today) and a slim band with ‹ › Today, and the strip's middle opens a calendar sheet of months (K2).

**Architecture:** Pure logic in `src/lib/exercises/` (`pastGroups` gains the entry's time; new `calendar.ts` builds the months from per-day counts). The past day's load adds the counts from the existing `listSetTimes` (runs on the device too, `sets` is synced). UI: `PastDay.svelte` rewritten, new `DayStrip.svelte` and `CalendarSheet.svelte`, `Screen` gets a slim-band-only snippet.

**Tech Stack:** SvelteKit 2, Svelte 5 runes, Tailwind, Drizzle/SQLite, vitest.

**Spec:** `docs/superpowers/specs/2026-11-09-past-days-design.md`

## Global Constraints

- Words through `t()`, in en and sl; sl: vikanje, `slCount`, » «; `no-english.spec.ts` green.
- Dates on screen built by hand (`format.ts`), never `toLocaleDateString`.
- No `Date.now()` in `src/lib/day`/`src/lib/schedule`; calendar logic takes `today` as an argument.
- A built control's colour is the builder's: never append `text-*` to a `styles.ts` builder's class.
- Components never import `$lib/server`; shared shapes in `src/lib/types.ts`.
- Safe area through `--safe-*`, never `env()`.
- No migration, no new table, no new GET endpoint.
- Check per task: `npx vitest run <files> --maxWorkers=4`, `npx eslint <files>`, `npx prettier --check <files>`; full `npm run check` only before the final review and after merging master.

## Review Focus

- A day with an archived exercise's entry: the row shows, is not a button, has no chevron; the calendar still counts it.
- The calendar at a month boundary and in a month starting on Monday (lead 0) or Sunday (lead 6).
- A shown day older than the first entry (an empty day reached by ‹ far back): the calendar starts at that month.
- A purged group's entry (`deletedGroupName`) keeps its name; only `Review: ` names are re-drawn.
- An entry with reps and no minutes, and one with neither: the line says "10:51 · 3 reps" / "10:51".
